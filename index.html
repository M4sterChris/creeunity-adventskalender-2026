Gut zu wissen

Ein Dezember voller CreeUnity

Jedes Türchen erscheint ab dem jeweiligen Dezembertag, sobald die tägliche Veröffentlichung abgeschlossen ist. Geplant ist der erste Lauf um 00:03 Uhr in Europe/Berlin; GitHub kann ihn verzögert ausführen. Frühere Türchen bleiben erreichbar.

Dein Fortschritt bleibt bei dir

Wir speichern die Nummern deiner geöffneten Türchen sowie gelöste Tagesrätsel und gesammelte Buchstaben im lokalen Speicher dieses Browsers. Testfortschritte bleiben getrennt in der Tab-Sitzung erhalten. Im Editor kannst du den GitHub-Zugang ausdrücklich für diesen Tab merken; „Abmelden“ entfernt ihn wieder. Deine Eingabe zur Rätselprüfung wird nicht an einen Server gesendet. Es gibt kein Tracking und keine Cookies dieser App. Bei extern eingebundenen Bildern erhält deren Anbieter beim Laden technische Verbindungsdaten, etwa deine IP-Adresse. Externe Links öffnen erst nach deinem Klick.

Deine CreeUnity-Werkstatt

Texte bearbeiten, Bilder hochladen und direkt privat speichern.

Zugang für mich oder andere einrichten
  1. Eigenen GitHub-Zugriffsschlüssel erstellen: unter „Only select repositories“ ausschließlich creeunity-adventskalender-2026-inhalte auswählen und „Contents: Read and write“ erlauben.
  2. Den Schlüssel hier einfügen. Optional kannst du ihn für diesen Tab merken, damit F5 die Verbindung wiederherstellt. Er wird ausschließlich an GitHub gesendet.
  3. Für weitere Bearbeiter kann der Repository-Inhaber je einen eigenen, zeitlich begrenzten Schlüssel mit derselben Repository-Beschränkung erstellen und später einzeln widerrufen. Schlüssel nur vertraulich weitergeben. Alternativ lässt sich direkter GitHub-Zugriff für Mitarbeitende einrichten.
